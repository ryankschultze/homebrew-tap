# homebrew-tap

Homebrew formulae for my command-line tools. Formulae here are written by each tool's release
CI; don't edit them by hand.

```sh
brew tap ryankschultze/tap
brew install macsetup
```

or in one step: `brew install ryankschultze/tap/macsetup`.

| Formula | What it is |
|---|---|
| [macsetup](https://github.com/ryankschultze/macsetup) | Terminal dashboard for a macOS setup engine (Apple Silicon) |
